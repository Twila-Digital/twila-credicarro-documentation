O Ambiente de desenvolvimento é projetado para permitir que você teste todas as funcionalidades da plataforma de forma segura e controlada.

## <Icon icon="flask" type="solid"/>  Como utilizar?

Quando criamos sua integração na Credicarro, ela é automaticamente configurada em STAGING. Neste ambiente:

- Todas as operações são simuladas
- Nenhuma transação real é processada
- Você pode testar todas as funcionalidades sem riscos
- Os dados são isolados do ambiente de produção

<Card title="Benefícios do Ambiente de desenvolvimento" icon="star" horizontal>
  * Teste suas integrações com segurança
  * Experimente diferentes cenários de propostas
  * Configure webhooks e receba notificações do andamento de sua proposta
  * Valide o fluxo completo da sua aplicação
</Card>

## <Icon icon="key" type="solid"/>  Usando o Ambiente de desenvolvimento

Para começar a testar:

1. Solicite a criação de uma chave/segredo de API para o Ambiente de desenvolvimento
2. Utilize estas credenciais para gerar seu token de autenticação e o utilize em suas requisições de teste
3. Solicite a configuração de um webhook para receber notificações de teste
4. Valide todos os fluxos da sua aplicação

<Card title="Dicas para Testes Efetivos" icon="lightbulb" horizontal>
  * Teste todos os cenários possíveis
  * Valide o tratamento de erros
  * Verifique as notificações de webhook
  * Confirme a integração com seu sistema
</Card>

## <Icon icon="arrow-right" type="solid"/>  Próximos Passos

Quando estiver confiante com sua integração:
1. Solicite a criação de uma chave/segredo de API para o Ambiente de produção
2. Aguarde a aprovação para produção
3. Comece a processar propostas reais
