## Como a notificação é enviada

Cada notificação é um `POST` com corpo JSON (`Content-Type: application/json`) e os headers:

| Header | Conteúdo |
| --- | --- |
| `Authorization` | Conforme o [tipo de autenticação](/pages/webhooks#tipos-de-autenticacao) do webhook (ausente quando for 1 - Sem autenticação). |
| `X-CrediCarro-Signature` | Assinatura HMAC do corpo, no formato `t={timestamp},v1={assinatura}`. |
| `Idempotency-Key` | Identificador da notificação. Retentativas da mesma notificação repetem a chave. |

## Assinatura HMAC-SHA256

Toda notificação de webhook é assinada com **HMAC-SHA256**, enviada no cabeçalho `X-CrediCarro-Signature`, para confirmar que a requisição veio da Credicarro e não foi forjada por terceiros.

```
X-CrediCarro-Signature: t=1715792400,v1=5f2b3c8e1a9d7c6b4e2f1a0d9c8b7e6f5a4b3c2d1e0f9a8b7c6d5e4f3a2b1c0d
```

- `t` — timestamp Unix (segundos) de quando a notificação foi enviada.
- `v1` — HMAC-SHA256 em hexadecimal minúsculo, calculado sobre a string `{t}.{corpo_bruto_da_requisição}`, usando o `segredo_assinatura` do webhook.

<Card title="Quando o segredo é gerado" icon="key" horizontal color="#25c2a0">
  O `segredo_assinatura` é gerado ao [cadastrar](/pages/webhook/create) o webhook e retornado **apenas nessa resposta** — ele não é devolvido por nenhuma outra consulta. Guarde-o com segurança.
</Card>

Para validar uma notificação:

<Steps>
  <Step title="Leia o header">
    Separe `t` e `v1` do header `X-CrediCarro-Signature`.
  </Step>
  <Step title="Monte o conteúdo assinado">
    Concatene o valor de `t`, um ponto (`.`) e o corpo da requisição exatamente como recebido, sem reformatar o JSON.
  </Step>
  <Step title="Calcule e compare">
    Calcule o HMAC-SHA256 desse conteúdo usando o `segredo_assinatura` como chave e compare com `v1` usando uma comparação de tempo constante (`timingSafeEqual`/`CryptographicOperations.FixedTimeEquals` — nunca `==` ou `Equals`).
  </Step>
  <Step title="Verifique o timestamp">
    Recuse timestamps (`t`) muito antigos para evitar reenvios maliciosos.
  </Step>
</Steps>

<CodeGroup>

```javascript Node.js
import crypto from "node:crypto";

const TOLERANCIA_SEGUNDOS = 300;

function assinaturaValida(rawBody, header, segredo) {
  const partes = Object.fromEntries(header.split(",").map((p) => p.split("=")));
  if (Math.abs(Date.now() / 1000 - Number(partes.t)) > TOLERANCIA_SEGUNDOS) return false;

  const esperado = Buffer.from(
    crypto.createHmac("sha256", segredo).update(`${partes.t}.${rawBody}`).digest("hex")
  );
  const recebido = Buffer.from(partes.v1 ?? "");
  return esperado.length === recebido.length && crypto.timingSafeEqual(esperado, recebido);
}
```

```python Python
import hashlib
import hmac
import time

TOLERANCIA_SEGUNDOS = 300

def assinatura_valida(raw_body: bytes, header: str, segredo: str) -> bool:
    partes = dict(p.split("=", 1) for p in header.split(","))
    if abs(time.time() - int(partes["t"])) > TOLERANCIA_SEGUNDOS:
        return False

    conteudo = partes["t"].encode() + b"." + raw_body
    esperado = hmac.new(segredo.encode(), conteudo, hashlib.sha256).hexdigest()
    return hmac.compare_digest(esperado, partes.get("v1", ""))
```

```csharp C#
using System.Security.Cryptography;
using System.Text;

static bool AssinaturaValida(string rawBody, string header, string segredo)
{
    var partes = header.Split(',').Select(p => p.Split('=', 2)).ToDictionary(p => p[0], p => p[1]);
    if (Math.Abs(DateTimeOffset.UtcNow.ToUnixTimeSeconds() - long.Parse(partes["t"])) > 300)
        return false;

    var hash = HMACSHA256.HashData(Encoding.UTF8.GetBytes(segredo), Encoding.UTF8.GetBytes($"{partes["t"]}.{rawBody}"));
    var esperado = Encoding.ASCII.GetBytes(Convert.ToHexStringLower(hash));
    var recebido = Encoding.ASCII.GetBytes(partes.GetValueOrDefault("v1", ""));
    return CryptographicOperations.FixedTimeEquals(esperado, recebido);
}
```

</CodeGroup>

<Note>
  A tolerância de 5 minutos é uma sugestão. Ajuste conforme a sua necessidade.
</Note>

<Warning>
  Sempre valide a assinatura contra o **corpo bruto** da requisição, antes de desserializar. Reformatar o JSON altera o hash calculado e invalida a comparação.
</Warning>

## Exemplo de endpoint

O endpoint precisa ler o **corpo bruto** antes de desserializar. Em Express:

```javascript
import express from "express";

const app = express();

app.post("/webhooks/credicarro", express.raw({ type: "application/json" }), (req, res) => {
  const rawBody = req.body.toString("utf8");
  if (!assinaturaValida(rawBody, req.get("X-CrediCarro-Signature") ?? "", process.env.CREDICARRO_SEGREDO)) {
    return res.sendStatus(401);
  }

  res.sendStatus(200);
  fila.publicar({ chave: req.get("Idempotency-Key"), evento: JSON.parse(rawBody) });
});
```

<Tip>
  Responda `2xx` assim que validar a assinatura e processe o evento de forma assíncrona (fila, job). O tempo limite de cada entrega é de 15 segundos.
</Tip>

## Respostas e retentativas

<Card title="Responda com 2xx" icon="check" horizontal>
  - Qualquer resposta `2xx` confirma o recebimento.
  - Respostas `408`, `425`, `429` e `5xx`, falhas de rede e tempo esgotado (15 segundos) são retentadas automaticamente.
  - As demais respostas `4xx` não são retentadas.
</Card>

## Deduplicação

<Card title="Trate o webhook como idempotente" icon="clone" horizontal>
  - Use o header `Idempotency-Key` como chave de deduplicação — uma retentativa da mesma notificação repete a chave.
  - As notificações podem chegar fora de ordem. Em propostas v2, use `data_evento` ou consulte a proposta para obter o estado mais recente.
</Card>

## Checklist de segurança

<Card icon="list-check" horizontal>
  * Valide a assinatura HMAC contra o corpo bruto, com comparação de tempo constante
  * Rejeite timestamps (`t`) muito antigos
  * Configure autenticação (Basic ou JWT) no cadastro do webhook, além da assinatura
  * Responda 2xx rápido e processe de forma assíncrona
  * Deduplique pelo `Idempotency-Key`
</Card>
