---
title: 'Criar cliente'
openapi: "POST /v1/customer"
---

Cria o cliente só com os dados pessoais. Para a proposta, complete depois com [endereço](/pages/customer/address) e [dados profissionais](/pages/customer/professional) — ou use o [endpoint unificado](/pages/customer/unified).

<Note>
  Este endpoint só cria. Se o CPF, o e-mail ou o celular já estiver cadastrado, retorna `409`.
</Note>
