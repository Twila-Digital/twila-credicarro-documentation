<Warning>
  Esta página documenta o webhook de propostas criadas pela **v1**. Propostas criadas pela v2 recebem o [webhook detalhado da v2](/pages/v2/webhooks).
</Warning>

Cada webhook ativo do tipo Proposta (`tipo` = 3) recebe uma notificação a cada atualização de status de uma proposta v1. Cadastro, autenticação, assinatura HMAC e retentativas funcionam igual nas duas versões — veja [Cadastrar webhook](/pages/webhook/create) e [Verificação e segurança](/pages/webhooks/security).

## <Icon icon="code" type="solid"/> Payload

Quando uma proposta criada pela v1 é atualizada, o payload enviado para o endpoint é um JSON com a seguinte estrutura:

```json
{
  "id_proposta": "00000000-0000-0000-0000-000000000000",
  "enum_status": 1,
  "status": "Analysing"
}
```

### Status enviados pelo webhook

Os valores abaixo são os status que podem ser enviados no campo `enum_status` do webhook de proposta v1.

<Tip title="Migrando para a v2?" horizontal>
