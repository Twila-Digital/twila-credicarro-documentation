Cada webhook ativo do tipo Proposta (`tipo` = 3) recebe uma notificação a cada atualização de status de uma proposta. Para cadastro, autenticação, assinatura HMAC e retentativas, veja [Cadastrar webhook](/pages/webhook/create) e [Verificação e segurança](/pages/webhooks/security).

## <Icon icon="code" type="solid"/> Payload

Quando uma proposta é atualizada, o payload enviado para o endpoint é um JSON com a seguinte estrutura:

```json
{
  "id_proposta": "00000000-0000-0000-0000-000000000000",
  "enum_status": 1,
  "status": "Analysing"
}
```
