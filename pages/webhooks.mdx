Webhooks permitem que sua aplicação receba notificações em tempo real sobre eventos importantes da Credicarro.

<Card title="Gerenciamento pela API" icon="gear" horizontal color="#25c2a0">
  Os webhooks podem ser cadastrados, consultados, editados e excluídos diretamente pela API de integração.
</Card>

## Disponibilidade dos webhooks

**Legenda:** 🟢 **Disponível** · ⚪ **Sem envio no momento**

## <Icon icon="mobile" type="solid"/> Segmentação de webhooks

<Card title="Ambientes e webhooks" icon="book" horizontal>
  Os webhooks são específicos para cada ambiente:
  - Webhooks criados em **desenvolvimento** recebem notificações apenas do ambiente de desenvolvimento
  - Webhooks criados em **produção** recebem notificações apenas de dados reais

  Saiba mais em [Ambiente de testes](/pages/development).
</Card>

## <Icon icon="key" type="solid"/> Configurar webhooks

Cadastre, liste, edite e exclua webhooks pelos endpoints do grupo **Webhooks**, nesta aba. Veja o [cadastro de webhooks](/pages/webhook/reference).

É permitido mais de um webhook por tipo; cada notificação é enviada para todos os webhooks ativos do tipo. Se preferir, o nosso atendimento também pode configurar os webhooks pelo e-mail <Icon icon="envelope" type="solid"/> atendimento@credicarro.com.br.

## <Icon icon="shield-halved" type="solid"/> Tipos de autenticação

Aceitamos três tipos de autenticação para os webhooks (`tipo_autenticacao`). O tipo e a credencial não podem ser alterados depois do cadastro; para trocá-los, exclua o webhook e cadastre outro.

<Card title="1 - Sem autenticação (não recomendado)" icon="triangle-exclamation" horizontal color="#ef4444">
  As notificações são enviadas para o seu endpoint sem nenhum cabeçalho de autenticação.
</Card>

<Card title="2 - Basic" icon="user-lock" color="#25c2a0" horizontal>
  Informe em `credencial` o valor em Base64 de `usuario:senha`. Cada notificação é enviada com o header `Authorization: Basic {credencial}`.
</Card>

<Card title="3 - Bearer JWT" icon="id-card" color="#25c2a0" horizontal>
  Informe em `credencial` o token. Cada notificação é enviada com o header `Authorization: Bearer {credencial}`.
</Card>

<Card title="Assinatura e retentativas" icon="signature" href="/pages/webhooks/security" horizontal>
  Além da autenticação, toda notificação é assinada com HMAC-SHA256. Veja como validar a assinatura e como funcionam as retentativas.
</Card>
