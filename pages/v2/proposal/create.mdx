---
title: 'Criar proposta'
openapi: "POST /v2/proposal"
---

Cria a proposta a partir da opção de simulação escolhida pelo cliente. A análise de crédito começa em seguida.

**Exemplo:**
```json
{
  "cpf": "12345678909",
  "simulacaoId": "123e4567-e89b-12d3-a456-426614174000"
}
```

<Tip title="Pré-requisitos" horizontal>
  Use um `id_simulacao` de uma simulação feita com `cnpjLoja`, e o cliente precisa estar com o cadastro completo (endereço, ocupação e renda). Senão, a API retorna `Simulation.Access.NotFromStore` ou `Customer.Account.Incomplete`.
</Tip>

<Note>
  Cada `id_simulacao` gera uma única proposta. Reutilizar um `simulacaoId` já usado retorna `422` com `Proposal.SimulationAlreadyActivated`; uma simulação expirada retorna `Proposal.SimulationAlreadyExpired`.
</Note>

<Tip title="Envie Idempotency-Key" horizontal>
  Assim, um timeout não cria duas propostas. Veja [Erros e idempotência](/pages/errors#reenvio-seguro-com-idempotency-key).
</Tip>

<Note>
  Acompanhe a proposta pelo [webhook de proposta](/pages/v2/webhooks) ou pela [consulta](/pages/v2/proposal/get).
</Note>
