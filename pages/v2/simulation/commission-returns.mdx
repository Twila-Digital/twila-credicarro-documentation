---
title: 'Retornos de comissão'
openapi: "GET /v2/proposal/simulation/commission-returns"
---

Retorna as **faixas de retorno de comissão** configuradas para a loja. Consulte antes de simular para saber quais valores de `retornoComissao` a loja aceita.

```json Resposta
{
  "retornos_comissao": [
    { "tipo": "Financing", "alvo": "Store", "retorno_minimo": 0, "retorno_maximo": 4, "permite_taxa_padrao": true },
    { "tipo": "Refinancing", "alvo": "Store", "retorno_minimo": 1, "retorno_maximo": 3, "permite_taxa_padrao": false }
  ]
}
```

| Campo | Descrição |
| --- | --- |
| `tipo` | Modalidade da faixa: `Financing` (financiamento) ou `Refinancing` (refinanciamento). |
| `alvo` | A quem a faixa se aplica: `Store` (loja) ou `Organization` (parceiro). A simulação valida pela faixa com `alvo` `Store`. |
| `retorno_minimo` / `retorno_maximo` | Menor e maior `retornoComissao` aceitos na simulação. |
| `permite_taxa_padrao` | Indica se a loja permite usar a taxa padrão. |

<Tip title="Como usar na simulação" horizontal>
  Envie `retornoComissao` em [Criar simulação de financiamento](/pages/v2/simulation/create-financing) ou [de refinanciamento](/pages/v2/simulation/create-refinancing) com um valor entre `retorno_minimo` e `retorno_maximo` da faixa do mesmo `tipo` e com `alvo` `Store`. O campo é opcional.
</Tip>

<Note>
  A lista vem vazia quando a loja não tem retorno de comissão configurado. Nesse caso, simule sem `retornoComissao` — se você enviar o campo, a API retorna `422` com `Store.CommissionReturn.NotConfigured`.
</Note>
