---
title: 'Criar simulação de financiamento'
openapi: "POST /v2/proposal/simulation/financing"
---

Calcula as condições de financiamento e retorna **uma opção para cada prazo elegível**, cada uma com o seu `id_simulacao`.

**Exemplo:**
```json
{
  "cpf": "12345678909",
  "placa": "ABC1D23",
  "valorVeiculo": 45000,
  "valorEntrada": 5000,
  "uf": "SP",
  "isVeiculoZeroKm": false,
  "cnpjLoja": "11.222.333/0001-81"
}
```

<Tip title="Pré-requisitos" horizontal>
  O cliente precisa estar [cadastrado](/pages/customer/unified) e o `cnpjLoja` vinculado ao seu cadastro de parceiro.
</Tip>

<Tip title="Entrada" horizontal>
  `valorEntrada` pode ser `0` e precisa deixar ao menos 10% de `valorVeiculo` para financiar. Só voltam os prazos cuja entrada mínima foi atingida — consulte a [faixa financiável](/pages/v2/simulation/range-financing). Se nenhum prazo servir, a API retorna `422` com `Proposal.DownPaymentInvalid`.
</Tip>

<Tip title="Retorno de comissão" horizontal>
  `retornoComissao` é opcional e precisa estar dentro da faixa [configurada na loja](/pages/v2/simulation/get-commission-returns) para financiamento. Omita o campo para usar a taxa padrão, quando a loja permitir.
</Tip>

<Note>
  Veja como ler cada campo da resposta na [referência de simulação](/pages/v2/simulation/reference).
</Note>
